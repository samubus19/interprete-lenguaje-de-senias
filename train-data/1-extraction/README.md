# 1-Extraction: Extracción de Puntos Clave

Esta carpeta contiene los scripts para extraer puntos clave (keypoints) de los videos de señas usando MediaPipe Holistic.

## Propósito
- Procesar videos de señas para extraer poses
- Generar archivos .npy con los keypoints
- Crear la estructura de datos necesaria para el entrenamiento

## Archivos
- `extract_keypoints.py`: Script principal para extracción
- `process_videos.py`: Procesamiento por lotes
- `utils.py`: Funciones auxiliares
