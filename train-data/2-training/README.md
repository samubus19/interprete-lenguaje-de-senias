# 2-Training: Normalización y Entrenamiento

Esta carpeta contiene los scripts para normalizar los datos de keypoints y entrenar el modelo de reconocimiento de señas.

## Propósito
- Normalizar longitudes de secuencias de keypoints
- Crear datasets de entrenamiento/prueba
- Entrenar modelos LSTM/GRU/Transformer
- Evaluar y generar predicciones

## Archivos
- `prepare_data.py`: Preparación y normalización de datos
- `train_model.py`: Script de entrenamiento
- `evaluate_model.py`: Evaluación y predicciones
- `model_architectures.py`: Definiciones de modelos
